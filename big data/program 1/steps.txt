Steps to run Program 1 (Record Count):

1. Create a folder for compiled classes:
   mkdir folder

2. Compile all Java files:
   javac -classpath $(hadoop classpath) -d folder RecordCountMapper.java RecordCountReducer.java RecordCount.java

3. Create a JAR file:
   jar -cvf recordcount.jar -C folder/ .

4. Create input directory in HDFS:
   hdfs dfs -mkdir /input

5. Upload your dataset to HDFS (replace dataset124.csv with your actual file):
   hdfs dfs -put dataset124.csv /input/data.csv

6. Run the MapReduce job:
   yarn jar recordcount.jar RecordCount /input /output

7. View the result:
   hdfs dfs -cat /output/part-r-00000
