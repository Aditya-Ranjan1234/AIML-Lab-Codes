
# Lab Programs Repository

This repository contains organized lab programs for **Big Data** and **Natural Language Processing (NLP)** courses.

## Repository Structure

```
lab programs/
├── big data/
│   ├── program 1/     # Record Count (MapReduce)
│   ├── program 2/     # Max Temperature (MapReduce)
│   ├── program 3/     # Movie Ratings (Pig)
│   ├── program 4/     # Temperature (Pig)
│   └── program 5/     # Movie Log (Hive)
├── nlp/
│   ├── program1.ipynb  # Text Summarisation
│   ├── program2.ipynb  # Word Cloud
│   ├── program3.ipynb  # TF-IDF + Logistic Regression
│   ├── program4.ipynb  # N-grams + Logistic Regression
│   ├── program5.ipynb  # Bag of Words + Naive Bayes
│   ├── program6.ipynb  # One Hot + Random Forest
│   └── program7.ipynb  # Topic Modelling (LDA)
└── README.md
```

## How to Run

### Big Data Programs
Each program folder contains a `steps.txt` file with detailed instructions to run.

### NLP Programs
Run the notebooks in Jupyter or VSCode by executing cells in order. All algorithms are implemented from scratch for educational purposes!

## Requirements
- For NLP: Python, Jupyter, NLTK, NumPy, Matplotlib
- For Big Data: Hadoop, Pig, Hive (or virtual machine like Cloudera)
